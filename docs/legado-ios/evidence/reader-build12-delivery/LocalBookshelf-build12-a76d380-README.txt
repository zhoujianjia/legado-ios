本地书架 build 12：自续签通道诊断版
源码：a76d380fdc108db83be68961905ee49edd209571

本版检查 RemotePairing 动态发现及同设备 TCP 连接。完整自动续签尚未实现；连接成功仅表示 TCP 可达，认证、签名和覆盖安装通道仍需后续验证。

安装
沿用现有签名方式、同一账号／团队及主 App、Widget、分享扩展的 Bundle ID 映射，重新签名后覆盖安装，保留当前 App 和书籍、书源、进度。不要先卸载。

验证
1. 这次将电脑关机并拔掉 USB，手机保持 Wi-Fi 连接，VPN 关闭。按你已说明的情况，不需要安装 SideStore。
2. 打开“设置 → 高级 → 自续签验证”，点击“开始连接验证”。检查最长约 8 秒；系统询问本地网络权限时允许该检查。
3. 完成后点击“导出验证报告”，保存 JSON。请同时保留电脑已关机、USB 已断开的运行条件说明。
4. 若未发现服务或连接超时，直接保留报告；无需连续重复，也不要提供 Apple ID 密码或配对文件。

报告仅导出诊断计数、状态与归一化错误，不导出服务名、地址或配对秘密。TCP 检查发送的业务载荷为 0；服务发现会使用系统 DNS-SD 查询。
